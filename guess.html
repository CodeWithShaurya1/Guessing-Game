Number guessing game

About the Game

This is a simple number guessing game created using JavaScript. The computer generates a random number between 1 and the maximum number entered by the user.

How to Play

  1. Enter the maximum number for the game.
  2. The computer will generate a random number between 1 and that maximum number.
  3. Try to guess the generated number.
  4. If your guess is wrong, you can try again.
  5. If your guess is correct, you win the game.
  6. Enter "quit" anytime to stop the game.

Example

If you enter 10 as the maximum number, the computer will generate a random number between 1 and 10.

Technologies Used

  • HTML
  • JavaScript
  • Math.random()
  • Loops and Conditional Statements

Game Features

  • Random number generation
  • Unlimited guesses
  • Win detection
  • Quit option
